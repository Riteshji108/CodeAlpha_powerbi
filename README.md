# CodeAlpha Power BI Internship Projects

This repository contains the completed work for **3 of the 4 Power BI tasks** in the CodeAlpha internship brief, which explicitly allows completing any 2 or 3 tasks.

## Completed Tasks

### Task 1 — Financial Health Dashboard
- Income statement and profitability analysis
- Cash flow and liquidity metrics
- Balance sheet metrics
- Forecasting guidance for budgeting and planning

### Task 2 — Human Resources Analytics
- Recruitment funnel and hiring metrics
- Employee turnover and retention
- Satisfaction and performance analysis
- Hiring-needs forecasting guidance

### Task 3 — Real Estate Market Trends
- Property price and rental-yield analysis
- Demand and supply conditions
- Geographic hotspot analysis using latitude/longitude
- Economic indicators and investment views

## Repository Contents

- `data/` — reproducible synthetic CSV datasets
- `DAX_Measures.md` — DAX measures for all three tasks
- `Power_Query_Setup.md` — Power Query import and typing setup
- `REPORT_BUILD_SPEC.md` — report pages, visuals, slicers, and layout guidance
- `VALIDATION.md` — data-quality and calculation checks

## Power BI Deliverable

The CodeAlpha brief asks for an interactive Power BI report/dashboard for each selected task. This repository contains the complete report specification, source data, Power Query setup, DAX measures, and validation notes needed to build the reports in **Power BI Desktop**.

A `.pbix` binary is not generated automatically here because it requires Power BI Desktop itself. The analytical source package is provided so the reports can be assembled reproducibly.

## Data Note

The datasets are **synthetic demonstration data** created for the internship project. They are intended for Power BI modeling, DAX, Power Query, and dashboard practice—not for real business decisions.

## How to Build the Reports

1. Open Power BI Desktop.
2. Import the CSV files from `data/` using **Home → Get Data → Text/CSV**.
3. Apply the typing/cleanup steps in `Power_Query_Setup.md`.
4. Add the measures from `DAX_Measures.md`.
5. Follow `REPORT_BUILD_SPEC.md` to create the report pages and visuals.
6. Run the checks in `VALIDATION.md` before publishing/exporting the report.

## CodeAlpha Brief Alignment

The supplied internship brief requires interns to complete any **2 or 3** of the 4 listed Power BI tasks and upload the completed source to GitHub in a `CodeAlpha_ProjectName` repository. This repository completes 3 tasks.
